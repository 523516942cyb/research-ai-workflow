# 研究工作流小工具箱

两个可以复用的工作流程，加两个能在浏览器里直接跑的单文件工具。
数据不出本机，不依赖任何服务。

## 里面有什么

| 目录 | 是什么 | 什么时候用 |
|---|---|---|
| `data-checkup/` | **数据体检**：字段盘点 → 五项体检 → 逐列判定 → 数据说明 | 拿到任何一张陌生表格；报告里要写"数据说明" |
| `weekly-report/` | **竞品周报**：固定字段 → 抽取 → 汇总 → 周报草稿 | 按周跟踪竞品与行业动态 |
| `demo/` | 两个单文件网页，双击即可打开 | 直接看效果 |

**demo**

- `demo/data-checkup.html` —— 拖入 CSV，自动输出：数据规模、完整率、重复行、列诊断（类型/缺失/离群/越界/未来日期）、问题清单，以及一段可直接贴进报告的"数据说明"。内置示例数据，点一下就能看。
- `demo/competitor-tracker.html` —— 竞品上新按固定字段成表，可按品牌/品类筛选，一键生成周报草稿。

## 为什么做这个

在市场研究的实习里，大量时间花在同一个问题上：**这份表能不能用、缺多少、该怎么处理、报告里该怎么写**。
每次重新想一遍很浪费，而且不同人、不同项目给出的说法还不一致。
所以把判断固化成流程，把重复的检查做成一个能跑的小工具——同一个问题只回答一次。

## 怎么用

1. 打开 `demo/data-checkup.html`，先点「载入示例数据」看输出长什么样
2. 换成自己的 CSV（Excel 里「另存为 → CSV UTF-8」）
3. 按 `data-checkup/SKILL.md` 的六步走一遍；需要提示词时看 `prompt.md`
4. 报告开头直接贴"数据说明"，附录留"处理记录"

## 三条原则

1. **只标记，不静默删除**：任何删除都要能说出来删了什么、为什么。
2. **缺失不猜测**：填不出来就写"未提及"。
3. **结论必须能指回表里**：指不回去的数字不出现在结论里。

## 说明

仓库里的数据均为示例，用于演示字段与流程，不是真实调研数据。
实际使用请替换为真实数据，并且不要把客户或项目数据放进这个仓库。
