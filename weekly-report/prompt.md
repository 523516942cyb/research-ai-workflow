# 提示词模板

四条，从抽取到成稿。使用时把方括号里的内容替换掉。

---

## ① 数据核对清单

```
我在做一份消费者问卷的交叉表核对。数据包含：样本 ID、分组变量（城市级别 / 性别 / 年龄）、
加权系数、各题项答案。

请列出一份核对清单，覆盖：有效样本数是否一致、加权合计是否为 1、每个交叉表的行列合计
是否等于总样本、百分比按行还是按列计算、多选题合计是否超过 100%。

输出表格：检查项 / 判断方法 / 异常示例 / 对应的 Excel 公式或 Python 代码。
```

---

## ② 开放题编码

```
以下是 N 条开放题回答，编码框架为 [列出框架]。

请逐条输出：归类（只能从框架中选）、置信度（高 / 中 / 低）、判断理由（不超过 20 字）。
无法归类的放进"其他"并说明原因。

输出为表格，不要改写原文。
```

---

## ③ 竞品新品信息抽取

```
请从以下页面内容中抽取新品信息，字段固定为：品牌 / 品类 / 新品名称 / 价格带 /
上市时间 / 核心卖点（不超过 15 字）/ 销售渠道 / 来源链接。

找不到的字段填"未提及"，不要推测。输出为表格。

页面内容：
[粘贴网页正文或商品详情]
```

---

## ④ 周报整合

```
下面是本周收集到的竞品上新信息（表格）。

请按品牌分组，组内按上市时间倒序，输出：
1）一张汇总表（列顺序保持原样）
2）3 条结论，每条必须能在表里找到依据，不允许出现表外数字
3）1 条"下周待补信息"

不要写"热度高""火爆"这类无法验证的判断；缺字段的写"未提及"。
```

---

## 使用习惯

- 一次只让模型处理一个来源 / 一个品牌，结果更稳
- 抽取和判断分两步：先只要表格，再单独要结论
- 结果进表之前先扫一遍"未提及"的字段，能补的补，补不到就留着
