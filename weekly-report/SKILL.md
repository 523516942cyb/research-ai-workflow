# 竞品新品周报

## 什么时候用

- 需要按周跟踪头部品牌的上新、价格与卖点变化
- 手里是一堆网页、截图、笔记，要先结构化再写报告
- 要求跨周可对比：字段不随人改，口径稳定

## 输入

每条新品至少包含：**品牌 / 品类 / 新品名称 / 价格带 / 上市时间 / 核心卖点 / 渠道 / 来源链接**。

缺哪个字段就写"未提及"，不要推测、不要用同类产品补齐。

## 步骤

1. **定字段**：开工前确认本周字段与上周一致。确实要加字段，就在文末的"字段变更"里记一行。
2. **抽取**：对每条来源单独跑一次「竞品新品信息抽取」提示词，一次只处理一个品牌的一个页面，避免串行。
3. **对齐**：按品牌分组，组内按上市时间倒序；同一天上新的按价格带从低到高排。
4. **判断**：每个品牌写 1 条观察点，只能基于表内信息——价格带是否下探、上新节奏是否变快、卖点是否趋同。
5. **输出**：先出表格，再出 3 条结论，最后列 1 条"下周待补信息"。
6. **复核**：结论里的每个数字都要能在表里指回去，指不回去就删掉。

## 输出格式

```
【竞品上新周报】

统计区间：YYYY-MM-DD 至 YYYY-MM-DD
覆盖品牌 N 个，收录新品 N 条

| 品牌 | 品类 | 新品 | 价格带 | 上市时间 | 核心卖点 | 渠道 |
|---|---|---|---|---|---|---|
| ...  | ...  | ...  | ...    | ...      | ...      | ...  |

结论
1. ...
2. ...
3. ...

下周待补
- ...
```

## 禁止

- 不要编造未提及的价格、上市时间和卖点
- 不要写"热度高""非常火爆"这类无法验证的判断
- 不要输出表里没有的数字
- 不要把示例数据当成真实上新信息
