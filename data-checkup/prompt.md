# 提示词模板

四条，覆盖"体检 → 清洗 → 说明 → 分析"。方括号里的内容按实际情况替换。

---

## ① 字段盘点与类型判断

```
这是一份 [问卷 / 工单 / 后台] 导出表，字段有：[列出字段名]。

请逐列判断：这一列属于数值 / 类别 / 日期 / 文本中的哪一种，判断依据是什么，
以及这一列在分析时最容易被误用在哪里。

如果字段名含义模糊，直接指出来，不要猜。
输出为表格：字段 / 类型 / 判断依据 / 常见误用。
```

---

## ② 生成清洗脚本（要求可回溯）

```
下面是一个 CSV 的字段结构与样例数据。

请写一段 Python（pandas）清洗脚本，要求：
1. 每做一步清洗，都打印"影响行数"
2. 删除类操作必须先把被删行导出到 dropped.csv
3. 缺失值不要自动填充，只标记
4. 最后输出一份清洗摘要（原始行数 / 清洗后行数 / 各步骤影响）

数据字段：[字段列表]
样例：[3–5 行]
```

---

## ③ 写"数据说明"段落

```
根据下面的体检结果，写一段 3–5 句的"数据说明"，用在报告开头。

要求：只陈述事实，不评价好坏；写明规模、完整率、缺失集中处、重复与异常的处理方式；
最后一句说明哪部分结论因此需要保留。

体检结果：
[粘贴：行数 / 列数 / 缺失 / 重复 / 离群 / 日期问题]
```

---

## ④ 交叉分析（限制在表内）

```
下面是清洗后的汇总表。

请做分组对比，输出 3 条结论。每条结论必须：
1. 能在表里指出具体数字
2. 给出方向与幅度（谁高、高多少）
3. 不出现表外信息，不做因果判断

如果某组样本量小于 N，请直接标注"样本不足，不建议下结论"。
```

---

## 使用习惯

- 体检和分析分两次问：先只要体检结果，确认后再要结论
- 让模型先给"检查项清单"，再让写脚本——比直接要脚本少一半返工
- 任何删除动作，都要求先导出被删行
