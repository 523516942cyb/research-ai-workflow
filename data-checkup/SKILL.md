# 数据体检

## 什么时候用

- 拿到一份不熟悉的表，要先决定"这份数据能不能支撑我要下的结论"
- 报告、复盘、周报里需要写"数据说明"
- 多份来源要合并，先得把字段与口径对齐
- 换人接手时，需要一份能看懂的数据现状

## 输入

一份表格（CSV / Excel 导出）+ 你要回答的问题（一句话，例如"这版满意度下滑是不是真的"）。

## 步骤

1. **字段盘点**：每列是什么、谁填的、什么口径、单位是什么。字段名含糊的（如"数值""状态"）必须回原始系统确认。
2. **五项体检**：
   - 缺失：哪些列缺、缺多少、缺失是否与分组有关（不是随机的缺失要单独说明）
   - 重复：完全重复行 vs 同一主体多条记录，两种处理方式不同
   - 类型混杂：数值列里混进"暂无""约 8000"，类别列写法不统一（"广州"/"广州市"）
   - 离群与越界：IQR 法标离群；量表类字段查是否超出取值范围
   - 不可能值：未来日期、负数金额、年龄 999、性别填成城市
3. **判定**：给每一列标一个状态——可用 / 需处理 / 不可用，并写一句理由。
4. **清洗动作**：默认"标记不删除"。任何删除都要能回溯：删了哪些行、依据是什么、删完还剩多少。
5. **分析**：先描述（分布、均值/中位数），再交叉（分组差异），最后才做推断（相关、回归、显著性）。
6. **输出**：数据说明 + 处理记录 + 结论 + 局限。

## 输出格式

```
一、数据说明（3–5 句，可直接贴进报告）
   规模、完整率、缺失集中在哪里、重复与异常如何处理、哪部分结论不可用

二、列诊断
   列名 / 类型 / 缺失 / 唯一值 / 范围 / 提示

三、处理记录
   动作 / 影响行数 / 依据

四、结论与局限
```

## 禁止

- 不做说明就删数据、填缺失值
- 没体检就给结论
- 把离群值一律当成错误（可能是真实长尾，也可能是录入错误，要回原始记录判断）
- 在报告里只写"已清洗"，不写清洗了什么
- 把示例数据当成真实数据下结论
